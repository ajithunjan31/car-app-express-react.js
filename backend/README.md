# Express setup 

Enter these commands in terminal one by one
```
npm init -y
npm i express 
```

dev dependency to automatic reload server
```
npm i -D nodemon
```
how to run with nodemon 
```
npx nodemon server.js
```


create server.js file in root directory 

your folder structure will look alike 
- nodemodules
- package-lock.json
- package.json
- server.js (which you create)

### Types of HTTP requests 
- GET 
- POST (eg: filling form, when we are creating some data)
- PUT (eg: to update data)
- DELETE (to delete data)
